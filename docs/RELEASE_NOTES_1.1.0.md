# Slip 1.1.0 — Glass, clarity, and speed

Slip 1.1.0 rebuilds the main sideloading workflow around native Liquid Glass, adds an adaptive light/dark glass icon, validates the complete install setup before signing, and substantially accelerates IPA preparation.

## Highlights

- A focused two-card destination/IPA workspace, segmented customization panes, live preflight results, and a persistent glass action dock.
- Automatic Glass, Light Glass, and Dark Glass icon modes plus native interface and motion preferences.
- Real IPA artwork in the import card and an exact connected-iPhone model preview with hardware-aware front details.
- Raw-copy processing for unchanged ZIP entries: a 196 MB Home Workout IPA improved from 4.42 seconds to 1.15 seconds on the release Mac.
- Early blocking for encrypted executables, incompatible minimum iOS versions, invalid bundle IDs, unavailable icon files, malformed typed values, duplicate keys, and protected identity overrides.
- USB-first manual installs, clearer Wi-Fi guidance, better App ID accounting, readable errors, and task timing.
- Scrollbar-free glass surfaces and corrected Dock contrast for the macOS Dark icon set.

## Important limits

Slip does not bypass Apple’s seven-day free-profile lifetime or three-app limit. Automatic refresh still requires this Mac, opt-in saved credentials, and a reachable paired iPhone. The downloadable build is development-signed and not notarized.
